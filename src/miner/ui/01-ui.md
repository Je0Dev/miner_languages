# 01 — UI Module

**`src/miner/ui/`** — `overlay.py`, `hover.py`, `dashboard.py`, `debug_monitor.py`, `web_viewer.py`, `__init__.py`

All user interfaces. Two Tkinter windows (live OCR overlay and yomitan hover), three Flask web apps (dashboard, text hooker, debug monitor).

## What each file does

### `overlay.py` — Live OCR Overlay (Tkinter)

**Class:** `LiveOCROverlay`

A frameless-ish Tkinter window where you select a screen region, then it auto-OCRs every 2 seconds and shows the result. 850×700px, 95% opacity, always-on-top.

**Buttons:**
| Button | What it does |
|--------|-------------|
| Select Region | Launches `slurp` to pick a region. |
| Start/Stop Live | Begins a 2-second OCR loop on that region. Auto-stops on too many errors. |
| Mine | Records audio + saves sentence + Anki CSV + universal log + copies to clipboard. |
| Split Preview | Shows how text will be split by `split_sentences()`. |
| Discard | Clears all text fields. |

**Auto-features:**
- **Auto-detect game** — reads active window class via `hyprctl activewindow`, loads per-game profile
- **Auto-hide** — after 15s of no text detected, iconifies the window
- **Auto-unhide** — when new text appears while hidden
- **Line merging** — detects continuing dialogue with overlap/prefix matching
- **MSSIM stability** — skips OCR during animations/scene transitions
- **Resolution change detection** — stops live mode if screen resolution changes
- **Multi-line buffer** — combines up to 20 lines over 30 seconds for context
- **Edit text** — if user edits the OCR text, it auto-re-translates in the background
- **Language radio buttons** — switch OCR/translate language on the fly
- **Parallel translation** — checkbox to use all 3 engines (Google + Libre + MyMemory)
- **Word breakdown** — shows per-word pinyin/romaji with definitions

**Live loop (`_start_loop`):**
1. Screenshot region → `grim -g geom tmp.png`
2. MSSIM stability check → skip if scene changing
3. OCR → `ocr_image()` or `ocr_long_text()`
4. Clean + filter + deduplicate
5. Line merging check (overlap/continuation)
6. Multi-line buffer combine
7. Translate + pronunciation
8. Update text fields + clipboard + universal log
9. Sleep 2s → repeat

### `hover.py` — Yomitan Hover (Tkinter)

A tiny 300×45px semi-transparent window. Drag it over game text — it auto-OCRs every 0.5s and copies to clipboard for Yomitan browser extension to pick up.

**How it works:**
1. Window is 85% transparent (`-alpha 0.85`), black background set as transparent color
2. Every 0.5s, hides itself briefly (80ms), takes a screenshot of its own position, OCRs, shows again
3. Waits for 3 identical consecutive OCRs before declaring text "stable"
4. Copies text to clipboard, sends to sentence server, saves to `yomitan_clipboard.json`
5. Only keeps text matching the current language's script (CJK/Latin/Greek/Cyrillic)
6. Single-instance via PID file at `/tmp/yomitan-hover/hover.pid`

**Labels:** Original text (`#00ff88`) + translation (`#ffdd57`). Draggable by clicking anywhere.

### `dashboard.py` — Stats Dashboard (Flask)

Simple Flask app on port 5001. Shows total mined, OCR failures, avg confidence, and per-language breakdown table. Dark theme, inline HTML templates.

| Route | What it shows |
|-------|-------------|
| `/` | Stats cards: total mined, OCR failures, avg confidence + per-language table |

| Function | What it does |
|----------|-------------|
| `run_dashboard(port)` | Starts Flask on `127.0.0.1:5001` |

### `web_viewer.py` — Text Hooker (Flask)

Flask app on port 5000 that reads `sentences.json` and serves a searchable web page. Allows filtering by language and searching by text/translation/pronunciation. Export CSV button.

| Route | What it does |
|-------|-------------|
| `/` | Web viewer with search + lang filter + export |
| `/api/sentences` | JSON of all mined sentences |
| `/api/export/csv` | Download CSV |

### `debug_monitor.py` — Hover Debug Monitor (Tkinter)

**Class:** `DebugMonitor` — 800×600px Tkinter window. Monitors `yomitan_clipboard.json` in real-time and shows captures, translations, errors, and clipboard entry count.

Refreshes stats every 0.5s. Buttons: Refresh, Clear Log, View Clipboard JSON.

### `__init__.py`

Empty — all UI files are run as standalone apps:
```bash
python src/miner/ui/overlay.py     # LiveOCR (keybind: SUPER+O)
python src/miner/ui/hover.py zh     # Yomitan hover (keybind: SUPER+Y)
python src/miner/ui/dashboard.py    # Dashboard (keybind: SUPER+CTRL+D)
python src/miner/ui/web_viewer.py   # Text hooker (keybind: SUPER+CTRL+V)
python main.py --dashboard           # Dashboard via CLI
```
